- Windows: `../scripts/clone-all.ps1`
- Linux/macOS: `../scripts/clone-all.sh`

|---|---|---|
| `Ni-Agent/` | https://github.com/YossefKhalil/Ni-Agent | DSH fork, Nivix Core, skills, interfaces |
